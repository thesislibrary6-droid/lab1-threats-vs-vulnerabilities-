# Threats vs Vulnerabilities

| No | Scenario | Category | Reasoning |
|:---:|---|:---:|---|
| 1 | A ransomware group encrypts all patient records in a hospital and demands payment in Bitcoin. | Threat | Ransomware attack — an external malicious actor actively causing harm to the organization. |
| 2 | A company's website login form does not validate user input, allowing SQL commands to be entered. | Vulnerability | Lack of input validation — a coding weakness that can be exploited through SQL injection. |
| 3 | A cloud storage bucket containing customer invoices is set to public access. | Vulnerability | Misconfiguration — sensitive data is exposed to anyone with the link. |
| 4 | Someone calls the IT helpdesk pretending to be the CEO and asks for an urgent password reset. | Threat | Vishing (voice phishing) — social engineering used to gain unauthorized access. |
| 5 | Employees have never attended any cybersecurity awareness training. | Vulnerability | Human weakness — untrained staff are more likely to fall for scams and attacks. |
| 6 | A flash flood damages the company's on-site data centre. | Threat | Natural threat — an environmental event that can destroy systems and data. |
| 7 | Administrator accounts can be accessed using only a password, without multi-factor authentication (MFA). | Vulnerability | Weak authentication — stolen passwords alone are enough to take over the account. |
| 8 | An attacker leaves malware-infected USB drives in the office car park, hoping staff will plug them in. | Threat | Baiting — a deliberate attack that uses curiosity to spread malware. |
| 9 | The office Wi-Fi router is still using the default username "admin" and password "admin". | Vulnerability | Default credentials — easily guessed login details that attackers can exploit. |
| 10 | A hacker on a café's public Wi-Fi intercepts traffic between users and websites. | Threat | Man-in-the-Middle (MitM) attack — actively eavesdropping on or altering communications. |
| 11 | The company's online shopping site uses HTTP instead of HTTPS. | Vulnerability | Unencrypted communication — data such as passwords and card details can be read in transit. |
| 12 | A former employee's account is still active three months after they resigned. | Vulnerability | Poor access management — unused accounts can be misused by the ex-employee or an attacker. |
